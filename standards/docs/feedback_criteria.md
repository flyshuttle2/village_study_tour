# 反馈评价体系

## 一、团队体验反馈

### 收集时机
活动结束后，邀请团队负责人/联系人填写

### 反馈内容

| 评价维度 | 评分标准 | 说明 |
|---------|---------|------|
| 总体满意度 | 1-5分 | 对活动整体感受 |
| 活动策划 | 1-5分 | 方案设计的合理性 |
| 活动完成度 | 1-5分 | 实际执行与预期的符合程度 |
| 带队人员 | 1-5分 | 教练表现 |
| 讲解水平 | 1-5分 | 内容讲解的专业性和吸引力 |
| 执教着装 | 1-5分 | 形象仪表 |
| 服务态度 | 1-5分 | 服务意识 |
| 时间把控 | 1-5分 | 行程安排的节奏感 |
| 场地卫生 | 1-5分 | 环境整洁度 |
| 场地安全 | 1-5分 | 安全保障措施 |
| 餐食口味 | 1-5分 | 菜品质量 |

### 评分说明
- **5分**：非常满意
- **4分**：比较满意
- **3分**：一般
- **2分**：不太满意
- **1分**：非常不满意

### 餐食专项评价
| 选项 | 说明 |
|------|------|
| 种类多样 | 菜品丰富，选择多 |
| 比较齐全 | 基本满足需求 |
| 菜品一般 | 无突出亮点 |
| 菜品单一 | 选择很少 |
| 菜品无特色 | 缺乏地方/活动特色 |

### 活动内容饱满度（多选）
- [ ] 创新性：有独特创新的设计
- [ ] 趣味性：生动有趣，互动性强
- [ ] 拓展性：有助于视野拓展
- [ ] 科普性：知识传递准确
- [ ] 人群针对性：适合参与人群

### 信息渠道
- [ ] 学校/机构合作
- [ ] 微信朋友圈
- [ ] 微信公众号
- [ ] 朋友介绍
- [ ] 其他平台推广

## 二、教练执教反馈

### 反馈类别

#### 1. 开场准备
**观察要点：**
- 是否使用普通话
- 语气和声音是否适合受众
- 是否讲解注意事项（秩序、规则、安全、科普意识）
- 讲解时态度是否严肃认真
- 着装是否符合要求
- 是否佩戴帽子/工牌

**优点示例：**
- 全程使用普通话，讲解语气和声音适合小朋友，简单易懂
- 时刻保持微笑，有亲和力，有活力

**改进建议示例：**
- 忽略参观前需要讲解注意的事项
- 讲解时尽量严肃一点，不要笑
- 不能玩弄道具
- 着装不标准（如未戴帽子、未穿教练服）

#### 2. 讲解内容
**观察要点：**
- 是否善于提问吸引注意力
- 是否能耐心回答问题
- 与学员互动情况
- 内容详略是否得当
- 是否有开场白和结束语

**优点示例：**
- 善于提问来吸引孩子注意力，引发思考
- 能够很好地回答小朋友提出的问题
- 和孩子们的互动强，氛围好

**改进建议示例：**
- 分发物料时太直接，没有讲解过程
- 开场时可以多讲解一些核心理念
- 某个环节讲解过长
- 忽略了某些区域的讲解
- 没有开场和结束语

#### 3. 路线组织
**观察要点：**
- 参观顺序是否合理
- 场地过渡是否有提示
- 是否关注掉队学员
- 线路规划是否完善

**优点示例：**
- 线路比较完善
- 会提醒小朋友们注意安全

**改进建议示例：**
- 参观顺序有问题
- 大门口没有讲解，直接从某个区域开始
- 去下一个场地没有提示和过渡
- 没有关注掉队的小朋友

#### 4. 专业内容
**观察要点：**
- 专业知识准确性
- 讲解是否有指引
- 内容深度是否适合受众

**优点示例：**
- 讲解内容非常详细，详略得当
- 有引导孩子们观察

**改进建议示例：**
- 对某些知识点不了解
- 有一些问题对小朋友来说太难了

#### 5. 工坊课程（如有）
**观察要点：**
- 物料准备是否到位
- 示范是否清晰
- 指导是否及时
- 是否给优秀作品展示机会
- 是否总结项目意义

## 三、数据应用

### 反馈数据用途
1. **服务质量监控**：跟踪各维度评分变化
2. **教练考核**：作为教练绩效参考
3. **内容优化**：根据建议改进活动设计
4. **培训需求**：识别培训重点方向

### 反馈闭环
1. 收集反馈 → 2. 分析数据 → 3. 制定改进 → 4. 执行落实 → 5. 跟踪效果
