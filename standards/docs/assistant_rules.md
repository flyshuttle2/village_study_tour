# 助教工作守则

## 一、保密原则

1. 一切关于费用的事宜，不询问、不回答
2. 不留任何私人联系方式给学员或家长
3. 自己的身份从属于上级，学员称呼统一使用自然名

## 二、言行规范

1. 活动期间全程禁酒
2. 在学员视线范围内禁烟、禁不文明行为、禁嬉闹
3. 全程使用普通话、文明用语
4. 有时间观念，禁止迟到早退
5. 着装要求：黑色或深色运动装/户外装，鞋子偏纯色，不要太花哨
6. 女教练长发时需扎发，保持干练整洁

## 三、大巴车跟车规范

### 上车确认
- 上车、下车时确认人数
- 若有名单需点名
- 若有异常情况，立即上报

### 安全提示话术（发车5-10分钟后）
> 大家好，欢迎大家参加本次活动，我是本车的跟车助理教练xx，接下来做安全提示：
> - 乘车时头手不伸出窗外
> - 坐稳扶好，有安全带的请系好安全带
> - 爱护车内环境
> - 行车时若有身体不适请呼叫"教练"
> - 在遵守以上规则的前提下，可自行组织节目互动
> 
> 祝大家愉快，谢谢。

### 下车提醒话术
> 大家好，我们即将抵达目的地。待车停稳后，依次下车，不要拥挤。下车带好所有物品，垃圾请放进垃圾桶。下车后找到教练集合整队。

## 四、整队规范

### 有队长时
> 请大家面向我，成两列纵队。大家请安静，请队长整队。

### 无队长时
1. 找一个合适的位置站定
2. 鸣哨
3. 大声说："请xx班/团队到我这儿集合"
4. 学员到跟前后，举起右手说："面向我，呈2列纵队，男生一列女生一列，高矮秩序，快速整队"
5. 队伍初步整理后，教练说"立正"，全体回应"1-2"
6. 教练说"请安静"

## 五、行进规范

### 开始行进
> 现在我们向前行进，目标xxx，大家保持队形，开始。

### 抵达场地/餐厅/卫生间
> 请大家依次排队进入，文明有序。

## 六、活动项目进行时

### 主教练授课时
- 助教需站在队伍侧面
- 成单列纵队
- 跨立姿势

### 学员练习时
- 分发相应道具
- 随队从旁关注
- 规则疑问可直接回答
- 回答不了的让学员稍等，询问主教练后再作答
- **不示范、不做方法上的提示**
- 可鼓励学员

### 学员正式挑战时
- 随队做好计时或计数
- 挑战结束成绩保密
- 跑步告知主教练
- 收纳物料
- 监督是否违规，鸣哨提示
- 执行相应惩罚
- 挑战结束告知主教练

### 紧急情况
- 若出现危险行为，立即制止
- 若在高空操作，助教从旁隔空保护

## 七、意外情况处理

### 上卫生间
- 未进行项目时：大部队申请则让第二助教整队带领前去，或全队行进路途中在卫生间门口等待，解决完毕后再整队带走
- 项目进行时：让两人成组，速去速回

### 恶意干扰秩序
1. 不点名提示一遍
2. 若继续干扰，则点名警告
3. 若继续干扰，则让干部/第二助教/老师隔离询问做工作
4. 助教不离开大队伍

### 安全事故
- **轻微流血性伤口**：指引去医务处处理
- **大面积流血性伤口/闭合性受伤（如脱臼骨折等）**：
  1. 安顿好大队伍
  2. 将伤员带离，避免二次受伤
  3. 询问并交给医务人员，专人看护
  4. 立即上报

### 打架斗殴
1. 一经发现，立即隔离
2. 禁止不文明言行制止
3. 大队伍休息时再处理
4. 立即上报

## 八、工坊课程规范

1. 提前准备好所有物料、场地
2. 学员到场后，先安顿有序就座，保持安静
3. 可以用1-3个问题引起兴趣，引出工坊主题
4. 动作示范要慢、要细
5. 物料发放要均匀
6. 自制/练习过程要随去指导
7. 给优秀作品展示分享的机会
8. 用几句话总结此项目的意义
