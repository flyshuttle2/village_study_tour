# 村庄研学魔法师

> 将十二年乡村研学经验蒸馏进 AI 智能体，为村庄文旅研学生成一揽子解决方案，让每个村庄都能拥有自己的研学魔法包

## 一、项目概述

### 1.1 项目定位

「村庄研学魔法师」是一个基于 AI 大模型的乡村研学解决方案生成系统。用户只需输入村庄名称和关键词，系统即可在数分钟内自动生成完整的研学旅行解决方案，包括课程教案、宣传海报、品牌视觉等全套内容。

### 1.2 解决的问题

传统研学方案开发面临的挑战：

| 环节 | 传统方式 | 本系统 |
|------|----------|--------|
| 方案撰写 | 人工 3-7 天 | AI 5 分钟 |
| 课程设计 | 需专业教研团队 | 自动生成 5 份教案 |
| 视觉物料 | 需设计师介入 | AI 生成海报/Logo |
| 运营支持 | 分散采购 | 执行表单自动生成 |

### 1.3 核心价值

- **降本增效**：将研学方案开发周期从数周缩短至数分钟
- **经验复用**：将十二年乡村研学运营经验固化为 AI 智能体
- **一键生成**：输入村庄名称 + 关键词，即可获得完整解决方案

## 四、环境配置

### 4.1 系统要求

- 操作系统：Windows / macOS / Linux
- Python：3.11 或更高版本
- 网络：能够访问 MiniMax API

### 4.2 安装步骤

```bash
# 1. 进入项目目录
cd village_study_tour

# 2. 创建虚拟环境（推荐）
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # macOS/Linux

# 3. 安装依赖
pip install -r requirements.txt
```

### 4.3 配置 API Key

在项目根目录创建 `.env` 文件：

```env
# MiniMax API Key（必须）
MINIMAX_API_KEY=your_minimax_api_key_here

# Lovart API Key（可选，用于图片生成）
LOVART_ACCESS_KEY=your_lovart_access_key
LOVART_SECRET_KEY=your_lovart_secret_key
```

> 获取 API Key：
> - MiniMax：https://platform.minimaxi.com
> - Lovart：联系 Lovart 官方获取

### 4.4 启动服务

**方式一：双击启动脚本**

```
双击运行「启动WebUI.bat」
```

**方式二：命令行启动**

```bash
cd village_study_tour
python app.py
```

启动成功后会显示：

```
乡村研学魔法师
==================================================
API Key 状态: 已配置
输出目录: C:\...\village_study_tour\output
启动 Gradio 服务...

```

### 4.5 访问服务

在浏览器打开：http://localhost:7860

## 六、输入说明

### 6.1 村庄信息（必填）

| 字段 | 说明 | 示例 |
|------|------|------|
| 村庄名称 | 村庄全称 | 龙潭村 |
| 省份 | 所在省份 | 福建省 |
| 城市 | 所在城市 | 宁德市 |
| 县区 | 所在县区 | 屏南县 |
| 乡镇 | 所在乡镇（选填） | 熙岭乡 |

### 6.2 关键词（选填）

关键词是系统生成特色体验课程的核心输入。

**设计理念**：关键词不是「非遗」「农耕」这种大类，而是更具体的词（如「土豆」「石拱廊桥」），系统自动推断类别并生成对应课程。

**输入格式**：多个关键词用空格分隔

**示例**：`土豆 石拱廊桥 黄酒`

**预设关键词列表**：

| 关键词 | 类别 | 生成课程 |
|--------|------|----------|
| 土豆 | 农耕体验 | 土豆的一生、美食工作坊 |
| 水稻 | 农耕体验 | 稻花香里说丰年 |
| 柿子 | 美食/手工艺 | 柿染植物染、柿饼制作 |
| 石拱廊桥 | 建造体验 | 达芬奇拱桥挑战、廊桥木作 |
| 木拱廊桥 | 建造体验 | 木拱廊桥营造 |
| 夯土 | 建造体验 | 夯土建筑体验 |
| 黄酒 | 非遗传承 | 古法酿酒体验 |
| 豆腐 | 美食制作 | 豆腐诞生记 |
| 竹编 | 手工艺 | 指尖上的竹编 |
| 四平戏 | 戏曲表演 | 走进四平戏 |
| 木偶戏 | 戏曲表演 | 指尖上的艺术——木偶戏 |

**关联度判断**：系统会自动计算关键词与乡村研学的关联度。关联度低于 0.6 的关键词会被忽略（如「无人机」「编程」等明显不相关的词）。

### 6.3 补充资料（选填）

| 资料类型 | 用途 | 格式 |
|----------|------|------|
| 村庄图片 | 帮助 AI 识别村庄风貌 | JPG/PNG |
| 地方文献 | 提升内容深度和准确性 | PDF（村史/乡志/县志） |

## 九、常见问题

### Q1: 启动失败，提示 `No module named 'xxx'`

**A**: 依赖未安装。执行：

```bash
pip install -r requirements.txt
```

### Q2: 端口 7860 被占用

**A**: 修改 `app.py` 中的端口号：

```python
demo.launch(server_name="0.0.0.0", server_port=7861)  # 改为其他端口
```

### Q3: 图片生成失败

**A**: 系统会按以下顺序尝试图片生成服务：

1. Lovart AI（优先，需配置 API Key）
2. MiniMax（备选，需配置 API Key）

检查 `.env` 文件中的 API Key 是否正确配置。

### Q4: PDF 生成失败

**A**: 系统会自动切换到备选方案：

1. WeasyPrint（优先，需要 GTK3 运行时）
2. ReportLab（备选，纯 Python，无需额外依赖）

如果 WeasyPrint 失败，终端会显示警告并自动使用 ReportLab。

### Q5: 关键词生成的课程为空

**A**: 检查关键词是否在预设列表中，或关联度是否过低。已知不相关的词（如「无人机」「编程」）会被自动忽略。

### Q6: 生成的方案内容不够准确

**A**: 上传地方文献 PDF（村史/乡志/县志），系统会基于文献内容生成更准确的方案。

## 附录 A：PDF 生成原理

### A.1 JSON → HTML → PDF 流程

```
JSON 数据
    │
    ▼
┌─────────────────┐
│ Python 字符串   │  # 用模板拼接 HTML
│ 模板构建        │
└─────────────────┘
    │
    ▼
HTML + CSS
    │
    ├──▶ WeasyPrint  ──▶ PDF（需要 GTK3）
    │
    └──▶ ReportLab   ──▶ PDF（纯 Python 备选）
```

### A.2 为什么用 HTML 作为中间格式？

- HTML + CSS 可以轻松实现复杂排版
- WeasyPrint 基于 WebKit 引擎，渲染效果与浏览器一致
- 相比纯代码生成 PDF，开发效率更高
