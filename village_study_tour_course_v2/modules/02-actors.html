🔧 Agent 工作原理

每个 Agent 的核心是 System Prompt，告诉 AI 扮演什么角色、怎么思考。

CODE 
SYSTEM_PROMPT = """
你是一个专注于中国乡村文旅
研学方案设计的专家AI...

## 核心方法论
1. 县域格局分析
2. 人文地理纵深
3. 研学价值定位

## 固定活动
- 村史馆参观
- 九宫格寻宝卡

## 输出格式
严格按JSON输出..."""
PLAIN ENGLISH

告诉 AI：你是乡村文旅专家

给 AI 分析问题的框架

规定必须包含的内容

要求输出 JSON 格式
