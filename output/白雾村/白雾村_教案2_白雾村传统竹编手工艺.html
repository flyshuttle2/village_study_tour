白雾村传统竹编手工艺DIY工作坊

类型：体验 | 板块：劳动

年级：小学3-4年级 | 时长：90分钟

地点：白雾村非遗手工艺展示馆 | 容量：30人

一、课程目标

知识：了解白雾村传统竹编技艺的历史与文化价值 / 认识竹编所需材料和基本工具 / 掌握基本的竹编编织技法

能力：学会基础竹编操作技能 / 提升动手实践能力和精细动作协调 / 培养耐心与专注的工匠精神

情感：感悟传统手工艺的文化魅力与非遗传承意义 / 树立保护和传承中华优秀传统文化的意识 / 培养对劳动的尊重和对传统手艺人的敬意

二、课程准备

教师：提前准备已处理好的篾条（宽约3mm， 长约40cm） / 准备竹编工具：篾刀、剪刀、钢尺、砂纸 / 准备样品：已完成和未完成的竹编作品 / 邀请村上竹编老艺人作为指导老师 / 打印或制作竹编步骤图解

学生：穿着便于操作的服装 / 修剪指甲，避免划伤篾条 / 带好水杯和毛巾 / 预习：简要了解中国竹编文化

安全预案

⚠ 篾条边缘锋利，易割伤手指 → 每位学生发放手套，操作前提醒注意安全，提供创可贴备用
⚠ 篾刀等工具使用不当 → 由老师统一管理工具，学生仅使用已处理好的篾条

三、实施过程

导入（10分钟）

引导员介绍今天的课程主题，讲述一个小故事：白雾村有一位王爷爷，他的手艺已经传了三代人，展示他编的精美竹篮，引发学生对竹编的兴趣

主体活动

活动1：探——探访竹编艺术馆（15分钟）

步骤：分组进入展示馆，每组配备一名志愿者引导 → 观察不同类型的竹编作品（篮、筛、席、帽等） → 找出这些作品的共同特点 → 思考：这些漂亮的竹编是怎么做出来的？

观察点：编织纹路的规律 / 不同成品的用途 / 竹编作品的精致程度

记录表：观察记录表

活动2：学——学习竹编技艺（30分钟）

步骤：老艺人自我介绍，分享学艺经历 → 讲解竹子的选取与处理（选竹-破篾-浸泡-杀菌-晾晒） → 示范基本技法：起头、压一挑一、收边 → 学生跟学简单动作，老师逐个指导 → 提问环节：有什么疑问？

观察点：篾条的柔软度控制 / 手法的一致性 / 力度与方向的控制

记录表：学习要点记录卡

活动3：创——亲手创作竹编作品（45分钟）

步骤：分发材料：篾条18根、泡沫垫板、图解说明书 → 学生按步骤开始编织： → 第1步：正确起头（5根篾条） → 第2步交替编织（压一挑一） → 第3步继续添加篾条至完成底面 → 第4步收边整理 → 老师巡回指导，鼓励学生互相帮助 → 完成后每人在作品上做记号（写名字或编号） → 进行作品展示与分享：学生介绍自己的作品和使用设想

观察点：编织的紧密程度 / 作品的完整性 / 创新设计的亮点

记录表：创作过程记录表

总结（10分钟）

1. 学生分享作品和心得 2. 老师点评优秀作品 3. 讲述竹编技艺的传承故事 4. 号召学生成为小小传承人，回到家后可以尝试用其他材料练习 5. 合影留念，颁发"白雾村竹编小匠人"纪念卡

四、评价

方式：过程性评价

量规：从三个维度评价：1.参与态度（是否积极参与、认真操作）-30% 2.技能掌握（能否正确使用编织技法、作品基本成型）-40% 3.创意表现（是否有自己的想法和设计）-30%

反思：今天你学会了什么新的技能？ / 在制作过程中遇到困难了吗？你是怎么解决的？ / 你认为传统手工艺为什么要传承下去？

五、附录

任务单：包含三个部分：1.探索观察页（记录看到的竹编作品特点）2.学习要点页（记录学会的技法）3.创作计划页（设计自己想做的作品样式）

素材：篾条（已处理好的竹篾） / 泡沫垫板 / 竹编步骤图解 / 作品展示台 / 纪念卡
