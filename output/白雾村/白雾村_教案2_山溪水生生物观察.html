山溪水生生物观察

类型：体验 | 板块：自然

年级：小学3-5年级 | 时长：90分钟

地点：白雾村山溪河段 | 容量：30人

一、课程目标

知识：认识白雾村山溪中常见的3-5种水生昆虫及鱼类 / 了解水生生物的生命周期和栖息环境 / 掌握基础的水质判断指标

能力：学会使用捕捞工具进行安全的水生生物观察 / 能够用文字和图画记录观察到生物的特征 / 培养团队协作和表达分享的能力

情感：激发对自然探索的兴趣与好奇心 / 树立水资源保护意识和生态文明观念 / 增强关爱生命、尊重自然的情感态度

二、课程准备

教师：准备捕捞网、观察盒、放大镜等观察工具 / 打印水生生物图鉴卡片 / 准备水质检测简易试剂 / 熟悉山溪地形和安全注意点

学生：穿着方便涉水的凉鞋或雨靴 / 自带笔记本和画笔 / 穿着适宜户外活动的服装 / 了解基本户外安全注意事项

安全预案

⚠ 山溪湿滑容易跌倒 → 选择水流平缓的安全观察区域，配备防滑鞋套，导师全程陪伴
⚠ 水中寄生虫或细菌感染 → 观察后提醒学生立即用清水洗手，避免直接饮用溪水
⚠ 蚊虫叮咬或蛇类出没 → 提前喷洒驱蚊液，导师检查环境并携带应急药品

三、实施过程

导入（10分钟）

在村委广场集合，导师介绍本次观察课程的主题和目标，强调观察礼仪和安全事项，分发观察工具，讲解基本操作方法

主体活动

活动1：溪流初探索（15分钟）

步骤：沿约定路线到达观察地点 → 导师介绍山溪的基本情况和水系分布 → 学生在引导下观察水流速度、水深、石头形状等自然特征 → 寻找可能有水生生物藏匿的水域区域

观察点：水流清澈度与颜色 / 岸边植物覆盖情况 / 岩石缝隙和淤泥分布 / 水面波纹和气泡位置

记录表：自然环境观察记录表

活动2：水生生物捕捞游戏（20分钟）

步骤：分组安排，每组4-5人 → 发放捕捞工具，讲解操作方法 → 各组在指定区域内进行限时捕捞 → 将捕获的生物放入观察盒中进行辨认 → 记录发现物种的数量和名称

观察点：不同生物的活动区域偏好 / 生物的外形颜色和行为特征 / 物种在生态系统中的位置关系

记录表：水生生物发现记录表

活动3：水生生物认知学习（30分钟）

步骤：导师展示各组发现的生物 → 对照图鉴讲解常见水生昆虫和鱼类的名称 → 介绍每种生物的生活习性和食物链关系 → 讲解水质变化对水生生物的影响 → 引导学生讨论如何保护山溪水资源

观察点：生物的身体结构和运动方式 / 不同种类的食性差异 / 水体颜色与清澈度的变化

记录表：生物特征认知学习卡

活动4：总结分享（15分钟）

步骤：各组派代表分享观察心得 → 导师点评和补充知识点 → 强调水资源保护的重要性 → 回收工具，整队返回

观察点：学生表达的完整性 / 对保护水资源理解的准确性

记录表：小组分享反馈表

总结（分钟）

四、评价

方式：过程性评价

量规：从探索参与度(25%)、观察记录完整性(25%)、团队协作表现(25%)、知识理解与表达(25%)四个维度进行综合评价，采用星级评价标准

反思：你在山溪中发现了哪些有趣的水生生物？ / 你认为水质好坏会影响哪些生物的生存？ / 我们可以通过哪些行动来保护山溪水资源？

五、附录

任务单：【山溪水生生物观察任务单】 1. 我在山溪中发现了____种水生生物，它们是：____ 2. 我最喜欢的水生生物是：____，因为：____ 3. 我认为应该这样保护我们的山溪水资源：____ 4. 用画笔画出你最想介绍给朋友的水生生物（背面）

素材：水生昆虫图鉴卡 / 淡水鱼类识别图 / 山溪流域地图 / 观察记录表模板 / 水质简易检测说明
