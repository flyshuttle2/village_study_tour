梯田农耕体验

类型：体验 | 板块：劳动

年级：小学3-4年级 | 时长：90分钟

地点：白雾村梯田示范区 | 容量：30人

一、课程目标

知识：了解梯田的形成原理和生态功能 / 认识云南高原地区的典型作物及其生长特点 / 理解‘粒粒皆辛苦'与农耕节气的文化内涵

能力：能够辨认基本农具并了解其用途 / 动手实践微景观制作，培养空间搭建能力 / 通过团队协作完成任务，提升沟通与配合能力

情感：体会农民劳作的艰辛，培养珍惜粮食的意识 / 感受中国传统农耕文化的智慧与坚守 / 建立对土地和自然的敬畏之心

二、课程准备

教师：联系白雾村农户作为在地导师，准备传统农具展示（图画或模型） / 打印农耕知识问答卡、微景观制作指导图 / 准备活动材料：小型种植盒、培养土、小石子、草坪垫、迷你作物模型、彩笔、卡片纸 / 确认活动场地安全，排除尖锐物和深水区域

学生：穿着舒适耐脏的运动服和运动鞋 / 自带小背包、水杯、防晒帽 / 课前了解一项家中常见的蔬菜或粮食作物

安全预案

⚠ 田间道路湿滑，部分田埂狭窄 → 每位学员配备防滑鞋套，全程由导师和助教陪同，不允许单独行动
⚠ 使用模拟农具时可能发生碰撞 → 活动前强调工具使用规范，分组时控制每组人数不超过6人
⚠ 天气炎热导致中暑 → 准备降温物品和避暑场地，设置充分的休息饮水点

三、实施过程

导入（10分钟）

在村口集合整队，导师介绍白雾村农耕传统历史，分享当地俗语‘哈尼梯田一千层’，引发学员对梯田的好奇心，提出本次课程的探索问题：我们为什么要梯田？梯田里种什么？

主体活动

活动1：探秘梯田（15分钟）

步骤：导师带领学员沿着梯田步道缓行参观 → 观察不同高度的梯田水位变化和作物生长差异 → 学员记录发现的农田设施（如水渠、闸门） → 向在地农户提问互动，了解梯田灌溉技巧

观察点：梯田的层级布局与等高线关系 / 田埂的筑造材料和方式 / 梯田水面的光泽和倒影

记录表：我的梯田观察记录表

活动2：农耕知识堂（30分钟）

步骤：地头课堂：导师讲解梯田农耕四季循环 → 展示当地主要作物图片（水稻、玉米、荞麦） → 介绍传统农具的演变和使用场景 → 二十四节气与农事安排的知识问答 → 学员复述并分享自家餐桌上的粮食来源

观察点：学员对农具功能的理解程度 / 对农耕文化传承的兴趣反应

记录表：农耕知识速记卡

活动3：田园游戏乐（20分钟）

步骤：分组：每组5-6人，推选组长 → 游戏一：‘插秧高手'比赛 - 用标记杆在框格内限时放置，看哪组摆放整齐有序 → 游戏二：‘颗粒归仓'接力 - 用小勺将‘稻谷'从一个容器运到另一个容器，限时完成 → 完成后集体回忆游戏中的感受，分享'农民伯伯真辛苦'的体会

观察点：团队协作的默契程度 / 面对任务困难时的坚持度

记录表：小组积分表

活动4：我的mini梯田（25分钟）

步骤：发放材料：种植盒、培养土、小石子、草坪垫、迷你作物模型 → 导师演示微景观梯田的制作步骤 → 学员独立制作：铺土-堆高-分层-筑埂-种植-装饰 → 完成后在卡片上写下自己的农耕体验感悟 → 优秀作品展示，每位学员简要分享

观察点：动手制作的专注程度 / 创意设计和审美表现

记录表：微景观制作评价表

总结（10分钟）

全体围坐田埂边，回顾今天的四个环节：探秘梯田看到了什么？学到哪些农耕知识？游戏中有什么感想？作品想送给谁？导师引导总结：梯田是祖先的智慧，我们要珍惜每一粒粮食。布置延伸任务：将制作的mini梯田带回家，继续观察养护，记录植物生长。

四、评价

方式：过程性评价

量规：采用星级评价：观察记录完整性（☆-☆☆☆）+ 知识掌握程度（☆☆-☆☆☆）+ 游戏参与积极性（☆☆-☆☆☆）+ 动手创作表现（☆☆-☆☆☆）+ 安全遵守情况（☆-☆☆☆），五项综合，满分五星

反思：今天你在梯田里发现了什么秘密？ / 如果你是农民，你最想做哪项工作？ / 以后吃饭时你会怎么做？
