梯田稻作文化探索

类型：探究 | 板块：人文

年级：小学5-6年级 | 时长：90分钟

地点：白雾村梯田观景点及村落非遗工坊 | 容量：30人

一、课程目标

知识：梯田的定义与功能 / 哈尼族梯田的历史沿革 / 传统稻作农具的种类与用途 / 梯田稻作相关的节气与民俗

能力：观察与描述自然地貌的能力 / 分析农业技术与环境适应关系 / 动手创作表达学习成果

情感：感受农耕文明的艰辛与智慧 / 增强文化遗产保护意识 / 培养热爱乡土文化的情感

二、课程准备

教师：提前勘察梯田观景点路线 / 准备梯田稻作图文展示材料 / 准备传统稻作农具实物或图片 / 准备创作材料：画纸、彩笔、黏土等 / 学习当地梯田历史与民俗故事

学生：穿着舒适户外服装和运动鞋 / 携带笔记本和铅笔 / 预习云南梯田基本知识 / 带好防晒或防雨用具

安全预案

⚠ 徒步过程中可能发生滑倒或摔伤 → 选择安全的观景步道，安排助教前后照应，携带应急医疗包
⚠ 天气炎热导致中暑 → 避开正午高温时段，准备足量饮用水，合理安排休息

三、实施过程

导入（10分钟）

在集合地点用多媒体展示云南梯田美景图片，激发学生兴趣；提出问题：'为什么要在山坡上修建梯田？梯田是如何形成的？'引导学生思考并初步讨论

主体活动

活动1：梯田地貌探索（15分钟）

步骤：导师带领学生沿安全步道前往梯田观景点 → 途中观察不同高度的梯田形态差异 → 到达观景点后，引导学生俯瞰梯田全貌，鼓励描述所见 → 聆听导师讲述梯田背后的故事：为何修梯田、如何历代修缮

观察点：梯田的层级分布 / 梯田与山势、溪流的关系 / 梯田水位与灌溉方式

记录表：梯田观察记录表

活动2：稻作文化系统学习（30分钟）

步骤：进入村落非遗工坊，参观传统稻作农具展览 → 导师逐一讲解每种农具的名称、功能和使用方法 → 通过图文展板学习梯田稻作的历史演变 → 了解传统稻种的种类及选种智慧 → 学习与稻作相关的节气习俗和节庆活动 → 互动问答：学生提问，导师解答

观察点：传统农具的材质与构造 / 稻作工序的时序安排 / 梯田文化与传统民俗的关联

记录表：稻作知识学习记录卡

活动3：梯田稻作主题创作（25分钟）

步骤：学生分组选择创作形式：绘画、微型模型或海报设计 → ，运用所学知识和观察所得进行创作 → 创作过程中导师巡回指导 → 完成后每组进行3分钟成果展示与介绍 → 其他学生和导师进行点评鼓励

观察点：作品的完整性 / 文化元素体现 / 创意表现

记录表：创作成果展示评价表

总结（10分钟）

全体学生回顾分享今日学习的最大收获；导师总结梯田稻作的文化价值与保护意义；引导学生思考：作为新时代少年，如何为传承农耕文化贡献力量；布置课后延伸任务：回家后向家人讲述今天的学习收获

四、评价

方式：过程性评价

量规：从探索参与度、知识掌握度、创作表现三个维度评价：探索环节观察记录完整性（20%）、学习环节知识掌握测试（40%）、创作成果的文化性与创意性（40%）

反思：梯田与平原稻田相比有什么特别之处？ / 如果不修建梯田，当地人民的生活会怎样？ / 我们今天学习的梯田文化对你有什么启发？

五、附录

任务单：包含三个部分：①梯田观察记录表（观察点勾选+文字描述）②稻作知识学习记录卡（知识要点填空）③创作设计草稿纸

素材：梯田实景图片 / 传统稻作农具图示 / 梯田建造历史图文展板 / 稻种标本图片 / 节庆活动照片
