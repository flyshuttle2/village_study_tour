白雾村民俗文化探访活动

类型：探究 | 板块：人文

年级：小学3-4年级 | 时长：90分钟

地点：白雾村村史馆与民俗广场 | 容量：30人

一、课程目标

知识：了解白雾村的主要乡村习俗和节庆活动 / 认识传统民俗物品及其文化含义 / 知道民俗文化与非遗手工艺的关联

能力：能够观察并描述看到的民俗文化元素 / 能够倾听并理解村民讲述的习俗故事 / 能够用语言或图画表达自己对民俗的理解

情感：增强对乡村传统文化的兴趣和好奇心 / 培养尊重和保护民俗文化遗产的意识 / 建立文化认同感和乡土情怀

二、课程准备

教师：走访白雾村事先确定可交流的村民 / 准备民俗展品图片或实物（如有） / 准备村史馆参观预约 / 了解当地主要的节庆习俗和传说故事 / 准备创作材料：彩笔、白纸

学生：课前了解自己家乡的节日习俗 / 穿着舒适的衣物和鞋子 / 携带小笔记本和铅笔 / 准备好一个问题打算询问村民

安全预案

⚠ 村内道路不平或狭窄 → 分组活动，有序行进，注意脚下
⚠ 与村民交流时的礼仪问题 → 提前强调基本礼貌用语和注意事项
⚠ 天气变化 → 准备雨具或遮阳帽

三、实施过程

导入（10分钟）

在村口集合，介绍今天的行程安排。通过问题导入：你知道我们国家有哪些传统节日？节日的习俗是什么？激发学生对民俗的好奇心。引导进入白雾村，观察村庄整体环境

主体活动

活动1：探访白雾村古民居（20分钟）

步骤：在老师带领下步行至村史馆沿途 → 观察传统民居的建筑特点（如瓦片、土墙、雕花等） → 观察村中是否保留有老的民俗痕迹如石磨、祭祀用品等 → 分发任务单，让学生记录观察到的民俗元素 → 简单与遇到的村民礼貌交谈，询问是否有特别的习俗

观察点：传统民居的建筑材料和风格 / 悬挂的装饰物品如灯笼、對联的意义 / 老物件的名称和用途 / 村民提及的节日习俗关键词

记录表：民俗发现记录表

活动2：村史馆与民俗课堂（40分钟）

步骤：村史馆工作人员或志愿者介绍白雾村历史沿革 → 观看民俗文化展板和实物展览 → 学习当地主要节庆活动：春节祭祖、火把节、收获节等的习俗和意义 → 了解传统手工艺与民俗的关系（如扎染、刺绣在节日中的用途） → 邀请一位熟悉民俗的老人讲述一个有趣的习俗故事 → 学生提问环节

观察点：展品的外观和使用方式 / 不同节庆的时间和相关习俗 / 传统手工艺品的图案寓意 / 老人讲述的故事细节

记录表：民俗知识学习卡

活动3：我的民俗创作（30分钟）

步骤：回顾今天探访和学习的内容 → 选择自己最感兴趣的一个民俗元素作为创作主题 → 用彩笔画出你理解的民俗场景，或用文字描述你的感受 → 写一段话介绍你的创作，说明为什么选择这个内容 → 小组内分享作品和创作想法 → 每组推荐1-2名代表全班分享

观察点：选择的主题是否能体现民俗文化特征 / 创作的完整性 / 表达的清晰程度

记录表：我的民俗创作记录表

总结（10分钟）

师生共同回顾今天探访的三个环节：用一句话说说你今天最大的收获。强调民俗文化是我们的宝贵遗产，要学会保护和传承。布置任务：回家后向家人了解自己家族的某个传统习俗，下次分享

四、评价

方式：过程性评价

量规：从三个维度评价：1.探索表现（积极观察、主动提问）-观察记录完整性；2.学习表现（认真听讲、积极思考）-知识掌握程度；3.创造表现（主题选择、创作表达）-作品完成度和分享积极性

反思：你最喜欢今天的哪个环节？为什么？ / 如果有机会，你还想了解白雾村的哪些民俗？ / 回家后你会怎样向家人分享今天的收获？

五、附录

任务单：民俗发现记录表：包括日期、姓名、班级、观察地点、发现的民俗元素（建筑、物品、习俗等）、我的疑问；民俗知识学习卡：包括节日名称、时间、主要习俗、我的新发现；我的民俗创作：主题画或文字描述、创作意图说明

素材：白雾村地图、村史馆展板内容、村民照片（如获取）、传统节庆图片、创作彩笔、白纸
