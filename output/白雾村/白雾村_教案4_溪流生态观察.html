溪流生态观察

类型：探究 | 板块：自然

年级：小学4-6年级 | 时长：90分钟

地点：白雾村山区溪流段 | 容量：30人

一、课程目标

知识：了解溪流生态系统的基本组成 / 掌握简易水质检测方法（pH值、浊度、水温） / 认识山区溪流常见的的水生生物

能力：能够正确使用简易水质检测工具 / 能够观察并记录溪流生态现象 / 能够团队合作完成探究任务

情感：增强保护水资源的环保意识 / 培养探索自然的科学兴趣 / 体会人与自然和谐相处的重要性

二、课程准备

教师：准备pH试纸、浊度对比卡、温度计等检测工具 / 准备放大镜、观察盒等观察器具 / 提前勘察溪流段落确保安全 / 准备溪流生物图鉴资料

学生：穿防水鞋或凉鞋便于涉水 / 携带笔记本和铅笔 / 穿着耐脏舒适的衣服 / 了解基础水循环知识

安全预案

⚠ 溪边湿滑可能摔倒 → 选择水流平缓区域，活动前强调安全注意事项，教师全程陪同
⚠ 蚊虫叮咬 → 预先喷洒驱蚊液，准备防蚊贴
⚠ 误食溪水 →

三、实施过程

导入（10分钟）

在村口集合出发，简要介绍本次探究主题，激发学生好奇心，讲述观察探索的基本方法（看、闻、摸、问），强调安全和环保要求

主体活动

活动1：溪流生态初探（20分钟）

步骤：到达溪流边，先安静用五官感受环境 → 分组自由观察溪流两岸，找到自己感兴趣的现象 → 用放大镜观察水中石头的青苔、水底沉积物 → 记录发现的植物、昆虫、泥沙等

观察点：水流速度与地形关系 / 水面波纹形成原因 / 岸边的植物分布 / 水中的悬浮物

记录表：探索发现记录表

活动2：水质检测趣味赛（30分钟）

步骤：讲解pH试纸使用方法并演示 → 每组领取检测工具，按分工进行检测 → 测量水温、pH值、记录浊度等级 → 各组汇报数据，比较分析差异 → 寻找并捕捉可见的小生物如小虾、小鱼蝌蚪等 → 对照图鉴识别物种

观察点：不同河段水质差异 / 水生物的栖息环境偏好 / 清澈与浑浊区域的对比

记录表：水质检测记录表

活动3：生态知识学习与分享（30分钟）

步骤：集中讲解溪流生态系统知识 → 介绍水生生物的食物链关系 → 讨论人类活动对溪流水质的影响 → 各组分享最有趣的发现 → 引导学生思考如何保护水资源 → 总结本节课的核心知识点

观察点：学生对知识的理解程度 / 参与分享的积极性

总结（10分钟）

回顾今天学到的新知识，邀请学生分享感受，布置课后思考题：在日常生活中如何做到节约用水、保护水源，总结本课程的意义，鼓励学生将学到的知识分享给家人

四、评价

方式：过程性评价

量规：观察记录完整性30%+检测操作准确性30%+团队协作表现20%+知识掌握程度20%

反思：你在溪流中发现了哪些有趣的事物？ / 水质检测结果说明什么？你认为这条溪流的生态环境好吗？ / 我们应该如何保护水资源？

五、附录

素材：pH试纸、浊度对比卡、温度计 / 放大镜、观察盒、捕捞网 / 溪流生物图鉴 / 探索发现记录表
