传统竹编手工艺

类型：体验 | 板块：人文

年级：小学3-6年级 | 时长：90分钟

地点：白雾村竹编工坊及周边竹林区域 | 容量：30人

一、课程目标

知识：竹子的种类及生长特性 / 竹编手艺的历史渊源与发展 / 竹编的基本工具：篾刀、钻子、卷尺等 / 竹编的四种基本技法：平编、绞编、立体编、装饰编

能力：能够正确使用竹编基本工具 / 掌握经纬交织的基本编织方法 / 独立完成简单竹编作品的制作 / 培养动手实践能力和空间思维能力

情感：感受传统手工艺的文化内涵与艺术价值 / 树立非遗保护与传承的意识 / 培养耐心细致、精益求精的工匠精神 / 增强对乡土文化的认同感和自豪感

二、课程准备

教师：提前预约当地竹编传承人作为教学指导 / 准备竹编工具：篾刀、钻子、卷尺、铅笔、划痕器等 / 准备竹材：剖好的篾条（宽约1cm，厚约0.1cm） / 收集竹编优秀作品用于展示观摩 / 打印或绘制竹编步骤图解

学生：穿着便于操作的衣服，不穿宽大飘逸服装 / 修剪指甲，避免钩挂篾条 / 携带笔记本和水彩笔用于记录和创作 / 提前了解竹编相关知识

安全预案

⚠ 篾条边缘锋利，可能割伤手指 → 提供防护手套，指导正确握持篾条的方法，篾刀使用时由传承人示范，禁止学生自行使用篾刀
⚠ 竹屑飞溅可能进入眼睛 → 指导学生在加工竹材时佩戴护目镜，保持适当距离
⚠ 长时间低头编织导致颈部疲劳 → 每20分钟安排短暂休息，活动颈部

三、实施过程

导入（5分钟）

在集合地点讲述竹编在白雾村的历史背景，展示几件精美的竹编艺术品，引发学生对竹编技艺的好奇心与学习兴趣

主体活动

活动1：竹林探索与竹材认知（15分钟）

步骤：带领学生步行至附近竹林，观察竹子的外部形态 → 通过触摸、嗅觉等方式认识不同竹子的质感 → 了解如何选取适合编织的竹材（三年生竹、节间均匀、无病虫害） → 参观竹编成品展示区，思考这些作品的编织方法

观察点：竹子的高度、节间长度、颜色变化 / 竹叶的形状与生长方式 / 竹编成品的编织纹理与结构

记录表：竹林观察记录表

活动2：竹编知识与技法学习（30分钟）

步骤：竹编传承人讲述竹编的历史故事（约5分钟） → 介绍竹编工具及其正确握持方法（篾刀、钻子等） → 示范四种基本编织技法的操作要点 → 学生跟练基础平编法：起头、压一挑一、交错编织 → 传承人巡回指导，纠正学生操作问题

观察点：篾条的握持姿势是否正确 / 经纬交织的规律是否掌握 / 拉力是否均匀适度

记录表：技法要点笔记

活动3：亲手编织竹编作品（40分钟）

步骤：分发篾条材料，每人约30根篾条 → 确定编织内容：方形杯垫或小型竹篮 → 先绘制编织草图，规划经纬数量 → 开始编织，从起头到收边独立完成 → 传承人适时给予个性化指导 → 作品完成后进行简单的后期整理

观察点：编织过程中的专注度 / 遇到困难的解决方式 / 作品的完整性和平整度

记录表：作品创作记录表

总结（10分钟）

学生展示自己的作品，分享创作感受；传承人点评并讲述竹编技艺的传承意义；引导学生思考如何将传统手工艺与现代生活结合；鼓励有兴趣的学生继续学习竹编，为非遗传承贡献力量

四、评价

方式：过程性评价

量规：从三个方面评估：(1)探索环节-观察记录完整性、提问主动性；(2)学习环节-技法掌握程度、练习认真度；(3)创作环节-作品完成度、创新尝试、专注程度。设优秀、良好、 待提高三个等级

反思：今天的竹编学习中，你觉得哪个环节最难？是如何克服的？ / 通过这次学习，你对传统手工艺有什么新的认识？ / 如果让你来改进或创新竹编作品，你会怎么做？

五、附录

任务单：包含四部分：①竹林探索记录（5项观察要点）②竹编知识要点 checklist③技法练习记录④作品创作档案（含设计草图、完成照、创作心得）

素材：竹编成品图片示例 / 工具使用示意图 / 四种基本编织技法图解 / 学生优秀作品参考图册
