梯田农耕体验之旅

类型：体验 | 板块：劳动

年级：小学3-6年级 | 时长：120分钟

地点：白雾村梯田区块 | 容量：30人

一、课程目标

知识：认识梯田的形成原理与地理特征 / 了解水稻的生长过程与习性 / 掌握基本的插秧技术与操作规范 / 知晓农耕文化的历史渊源与价值内涵

能力：能够正确识别秧苗与本田的区别 / 能够掌握规范的插秧动作要领 / 能够在实践中体验劳动的艰辛与收获 / 能够与同伴协作完成农事任务

情感：培养热爱劳动、珍惜粮食的情感 / 增强对传统农耕文化的认同感 / 树立人与自然和谐共生的生态观念 / 感悟农耕智慧中蕴含的勤劳精神

二、课程准备

教师：联系当地农户提供秧田与技术指导 / 准备草帽、套鞋、水桶等农具 / 印制《梯田农耕任务单》 / 准备农耕号子音频与教学资料 / 考察天气与田地蓄水情况

学生：穿着耐脏便于活动的服装 / 自带饮用水与防晒用品 / 预习水稻基本知识 / 了解袁隆平与杂交水稻的故事

安全预案

⚠ 田埂湿滑摔倒 → 选择水位适中的试验田，安排助教全程陪护，提醒学生缓慢行走
⚠ 蚊虫叮咬或水蛭吸附 → 提前喷洒驱蚊药水，准备防扎裤袜，检查有无蜈蚣、蚂蟥等
⚠ 长时间弯腰导致身体不适 → 每15分钟安排休息，备好姜茶驱寒，及时补充水分

三、实施过程

导入（10分钟）

在村口集合，讲述白雾村梯田的历史故事，展示梯田四季变换的图片，激发学生对农耕体验的好奇心与向往

主体活动

活动1：探秘梯田（20分钟）

步骤：沿着田埂步行，观察梯田一级级盘旋而上的壮观景象 → 寻找梯田的灌溉进水口与排水口，分析水的流动方向 → 观察梯田边上的野花杂草，认识哪些是稻田常见的伴生植物 → 用工具测量一块试验田的长宽，计算面积

观察点：梯田的层级划分与坡度特征 / 梯田水系的布局与水源补给 / 泥土的有机质含量与颜色差异

记录表：《梯田探秘记录表》

活动2：农耕知识堂（30分钟）

步骤：农户示范正确的插秧姿势：双脚分立、身体下蹲、左手分秧、右手插秧 → 讲解插秧的深度间距要求：三指握秧根、插入泥中两厘米、株距六寸 → 学唱本地传统的插秧号子：'嘿呦嘿呦加油干呦' → 认识秧苗与稗草的区别，避免误植杂草丛中

观察点：插秧手势的专业与否直接影响成活率 / 农耕号子协调节奏、激励士气的作用 / 传统农谚中蕴含的节气智慧

记录表：《农耕知识笔记本》

活动3：插秧趣味赛（25分钟）

步骤：分组进行插秧接力赛，每组成员依次完成5株秧苗的插种 → 开展'火眼金睛'辨认赛：找出混在秧苗中的稗草 → 进行插秧速度与质量的评比，评选'插秧小能手' → 胜利组获得农户奖励的特色土特产一份

观察点：团队协作的默契程度 / 插秧动作的规范与效率平衡 / 参与热情与良性竞争氛围

记录表：《趣味比赛计分表》

活动4：下田实践（25分钟）

步骤：分组进入各自的试验田，开始正式的插秧实践 → 每位学生亲手栽种10株秧苗，记录自己的劳动成果 → 在田边竖立个人名牌，写上姓名与栽种日期 → 约定待到秋收时节重返梯田，观察自己种下的水稻生长情况

观察点：秧苗栽种的深浅与角度是否正确 / 植株行距是否均匀整齐 / 学生的投入程度与情感变化

记录表：《我的秧苗成长档案》

总结（10分钟）

集中在田边大树下，回顾今天的体验感受，分享'粒粒皆辛苦'的心得体会。引导学生思考农民的不易与粮食的珍贵，鼓励学生将今天的体验写成日记，带给家人朋友分享

四、评价

方式：过程性评价与成果展示相结合

量规：从探索发现(20%)、知识掌握(20%)、游戏参与(20%)、劳动实践(30%)、团队协作(10%)五个维度进行综合评定，重点关注学生参与过程中的态度积极性和技能掌握程度

反思：今天你亲手插下的秧苗，你想对它说些什么? / 通过这次体验，你觉得农民伯伯不容易在哪里? / 如果你来设计一座理想中的梯田，你会怎么规划?
