乡村节庆文化探秘

类型：探究 | 板块：人文

年级：小学5-6年级 | 时长：90分钟

地点：白雾村村民活动中心 | 容量：30人

一、课程目标

知识：了解白雾村所在地区的主要的传统节日及其文化内涵 / 认识节日与农耕生产、 local 民俗的关联 / 掌握基本的调研方法和文化记录技巧

能力：能够通过观察和交流收集民俗信息 / 能够整理和归纳文化知识形成简单报告 / 能够用图画和文字结合的方式表达文化理解

情感：增强对乡村传统文化的兴趣和认同感 / 培养尊重不同文化习俗的意识 / 建立文化保护与传承的意识

二、课程准备

教师：收集白霧村及会泽地区节庆活动的照片、视频资料 / 准备白纸、彩笔、A3画纸等创作材料 / 了解当地特色的节日习俗（密枝节、火把节等彝族节日）

学生：提前了解自己家乡的传统节日 / 每人准备一支彩色水笔或马克笔

安全预案

⚠ 在使用剪刀等工具时可能造成划伤 → 提供安全剪刀，指导正确使用方法，安排助教协助

三、实施过程

导入（10分钟）

出示几张彩色节日活动照片，引导学生观察并提问：'图中人们在进行什么活动？' '这些活动让你想到了什么节日？'

主体活动

活动1：探索节庆习俗（15分钟）

步骤：播放白雾村往年纪录片片段，展示节日setup 和庆祝场景 → 引导学生仔细观察画面中人们的服饰、动作、场地布置 → 鼓励学生提出感兴趣的问题并记录在问题卡上

观察点：节日现场的环境布置特点 / 人们庆祝时的表情和动作 / 传统服饰和装饰物品

记录表：问题收集卡

活动2：学习节日知识（35分钟）

步骤：教师介绍云南会泽地区主要传统节日：火把节（彝族新年）、密枝节等 → 讲解各节日的由来、庆祝时间、主要活动和 代表食物 → 说明节日与当地农耕生产、自然环境的关联 → 组织知识抢答互动，巩固学习内容

观察点：学生对不同节日的理解程度 / 积极参与互动的表现

记录表：节日知识记录表

活动3：创作节日海报（40分钟）

步骤：学生分成5-6人小组，每组选择一个学习的节日主题 → 组内分工：绘画、书写、设计、讲解等角色 → 共同在A3画纸上完成节日海报创作 → 各组依次上台展示作品并简要讲解

观察点：团队协作情况 / 创意表现形式 / 展示表达的自信度和条理性

记录表：小组合作评价表

总结（10分钟）

教师引导回顾本课学习内容，强调乡村传统文化的重要价值，鼓励学生回家后向家人了解家族的节日传统，完成'我的家庭节日故事'简短视频拍摄

四、评价

方式：过程性评价

量规：观察记录学生在探索环节的提问质量、学习环节的参与程度、创作环节的团队合作和作品完成情况进行综合评价

反思：你最喜欢哪个节日习俗？为什么？ / 如果要向朋友介绍今天学的节日，你会怎么说？ / 你认为保护这些传统节日重要吗？怎么做？

五、附录

任务单：节日探秘任务单：1.记录你最感兴趣的3个问题；2.学习3个以上节日知识要点；3.小组海报需包含：节日名称、庆祝时间、主要活动、象征意义、代表颜色或图案

素材：白雾村节庆活动照片集 / 云南彝族节日介绍资料 / A3彩色画纸 / 彩笔套装 / 问题收集卡片 / 节日知识记录表
