乡村节庆民俗体验

类型：探究 | 板块：人文

年级：小学5-6年级 | 时长：90分钟

地点：白雾村民俗文化广场及传统村落保护区 | 容量：30人

一、课程目标

知识：了解白雾村主要传统节庆的时间、由来及意义 / 认识乡村节庆仪式中的代表性物品与象征符号 / 掌握当地节庆活动的具体流程和民俗禁忌 / 理解传统文化在乡村振兴中的价值和作用

能力：能够通过观察和访谈收集民俗文化信息 / 能够分析和解读民俗活动背后的文化内涵 / 能够运用所学知识进行创意设计和展示表达 / 能够与他人合作完成小组探究任务

情感：培养对乡村传统文化的兴趣和尊重 / 增强文化遗产保护意识和社会责任感 / 激发对乡土文化的认同感和自豪感

二、课程准备

教师：白雾村节庆民俗资料包（包括全年节日时间表、典型节庆介绍、仪式流程图） / 访谈提纲和记录表 / 当地节庆视频或图片资料 / 手工创作材料（彩纸、剪刀、胶水、颜料等） / 分组任务卡

学生：提前了解家中或身边接触过的传统节日 / 穿着舒适的服装和运动鞋 / 自带水杯和笔记本 / 准备1-2个关于乡村节庆的问题

安全预案

⚠ 村寨参观过程中道路不平整 → 由熟悉地形的村民向导带领，慢行注意脚下
⚠ 与村民互动时的语言沟通障碍 → 安排当地老师或翻译陪同，确保交流顺畅

三、实施过程

导入（10分钟）

引导学生回忆自己经历过的传统节日（如春节、中秋节），提问：你们家过节的时有什么特别的活动？引发学生对'什么是节庆民俗'的思考和讨论，自然过渡到白雾村的乡村节庆主题

主体活动

活动1：村落探访（20分钟）

步骤：分组说明：每组4-5人，领取探访任务卡（包含需要寻找的民俗信息点） → 在村民向导带领下进入传统村落，观察建筑装饰、节庆痕迹、民俗物品 → 小组成员分别对指定村民进行简短访谈，记录关键信息 → 各组整理收集到的信息，准备分享

观察点：村中是否有节庆留下的装饰、标语或特殊物品 / 村民提及最多的节日是什么 / 传统节庆中有哪些必不可少的环节

记录表：民俗信息收集表

活动2：民俗讲堂（35分钟）

步骤：邀请当地民俗传承人或村长讲述白雾村重要节庆的故事 → 展示白雾村年度节庆日历，标注时间、名称、主要活动 → 结合图片或视频介绍代表性节庆仪式的具体环节 → 讲解传统节庆中各类物品的象征意义和文化内涵 → 学生自由提问，与讲述人互动交流

观察点：各类节庆的时间节点和季节特征 / 仪式中不同物品代表的寓意 / 老一辈与年轻人对待传统节庆的态度差异

记录表：民俗知识笔记

活动3：创意展示（25分钟）

步骤：小组讨论：结合探访和学习所得，为白雾村设计一个创意节庆活动方案，或制作一件民俗手工艺品 → 提示：可设计新的节庆宣传海报、纪念品，或改良传统习俗的现代玩法 → 各组依次上台展示创意方案，说明设计理念 → 其他组员和老师进行简单点评

观察点：创意是否体现对传统文化的理解 / 方案是否具有在村里实行的可行性 / 展示表达是否清晰有感染力

记录表：创意设计方案表

总结（10分钟）

教师引导回顾本节课的三环节：探访发现了什么、学到了哪些知识、创玩了什么创意。请学生谈谈感受最深的收获，以及如何将今天的学习带回家中。布置延伸任务：用文字、绘画或视频记录家中下一次节日的情形，对比今天所学

四、评价

方式：过程性评价

量规：参与度（20分）+ 信息收集完整性（25分）+ 知识理解准确性（25分）+ 创意设计新颖性（20分）+ 团队合作表现（10分）

反思：白雾村的节庆民俗与你所在城市的节日有什么相同和不同？ / 如果你生活在白雾村，你想参与哪个节庆活动？为什么？ / 如何让更多人了解和传承这些乡村传统节庆文化？

五、附录

任务单：【探访任务卡】 1. 寻找村中近年节庆活动留下的痕迹（如横幅、对联、装饰等） 2. 访谈一位村民：请他讲述记忆最深的一个春节俗/庆典 3. 记录村里一种传统食物及其在节庆中的用途 4. 观察村中老年人和年轻人对节庆态度的差异 【创意设计要求】 为白雾村设计一个方案，可选方向： A. 设计一个传统节庆的现代宣传方案 B. 制作一个节庆主题的手工作品 C. 设计一个适合游客参与的体验项目 方案需说明：设计灵感来源、预期效果、实施建议

素材：白雾村节庆民俗资料册 / 访谈记录表 / 各类纸张和彩笔 / 剪刀、胶水等基础手工材料 / 少数民族服饰图片参考 / 传统节庆仪式图片
