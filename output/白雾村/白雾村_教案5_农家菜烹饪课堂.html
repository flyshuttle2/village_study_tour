农家菜烹饪课堂

类型：体验 | 板块：劳动

年级：小学5-6年级 | 时长：120分钟

地点：白雾村农家乐厨房 | 容量：30人

一、课程目标

知识：认识白雾村当地常用蔬菜和香料 / 了解农家菜的基本烹饪原理和方法 / 掌握土灶生火和控制火候的基本技巧

能力：提升动手实践能力和烹饪操作技能 / 培养团队协作和分工配合意识 / 提高观察力和色彩搭配审美能力

情感：体验乡村饮食文化的独特魅力 / 感受自给自足的农耕生活方式 / 珍惜食物来之不易，培养节约意识

二、课程准备

教师：准备厨师服、围裙、帽子等烹饪装备 / 提前采购当地新鲜农产品和调味料 / 准备烹饪工具：刀具、砧板、铁锅、土灶柴火 / 准备农家菜食谱卡和安全须知 / 与当地村民厨师沟通教学流程

学生：穿着舒适方便活动的服装 / 不留长发或扎好头发 / 修剪指甲，洗净双手 / 了解基础的厨房安全和灭火知识

安全预案

⚠ 刀具和火源使用可能造成割伤或烫伤 → 每组配备1名成人全程指导监督，使用儿童安全刀具，佩戴防护手套，注意与灶火保持安全距离
⚠ 土灶柴火可能引发火灾隐患 → 准备灭火器和湿毛巾，确保逃生通道畅通，生火前检查灶台周围无可燃物
⚠ 地面湿滑可能导致摔倒 → 保持地面干燥整洁，穿防滑鞋，注意行走安全

三、实施过程

导入（10分钟）

在农家乐门口集合，发放围裙和厨师帽，进行简单热身游戏活跃气氛，讲述今天课程的目的和流程安排，介绍当地传统农家菜文化背景

主体活动

活动1：菜园探索（15分钟）

步骤：分成5个小组，每组6人 → 沿着菜园小径行进，由村民介绍各类蔬菜名称和生长特点 → 每人领取一张植物观察记录表，记录至少5种蔬菜的特征 → 返回教室后小组分享发现，互相补充认识的蔬菜种类

观察点：观察蔬菜的外形特征、叶片形状、颜色 / 注意观察田间的种植方式和生长环境 / 寻找当地特有的香料或调味植物

记录表：菜园植物观察记录表

活动2：烹饪演示（30分钟）

步骤：请当地村民厨师现场示范炒青菜的完整过程 → 讲解土灶生火的步骤和要点，演示如何控制火候 → 示范基本刀工：切菜姿势和手法 → 讲解调味品的添加顺序和用量比例 → 学生边观看边记录关键步骤 → 示范完成后请学生提问，解答疑惑

观察点：火候变化的时机和表现 / 刀具使用的正确姿势 / 调味时的动作和用量判断

记录表：烹饪步骤记录卡

活动3：烹饪大挑战（20分钟）

步骤：进行农家菜烹饪知识抢答竞赛 → 每组抽取一道菜品名称，需说出主要原料和烹饪步骤 → 角色扮演游戏：一人扮演厨师，其他人扮演助手配合工作 → 模拟练习：用手势比划正确的切菜和翻锅动作 → 积分最高的小组获得"最佳厨神团队"称号

观察点：回答的准确性和反应速度 / 团队配合的默契程度 / 对烹饪知识的理解和记忆

记录表：竞赛积分卡

活动4：烹饪实践（30分钟）

步骤：各小组就位土灶，领取所需食材和工具 → 按照之前学习的步骤，分工合作完成一道农家菜 → 村民厨师和老师巡回指导，及时纠正错误操作 → 菜品完成后进行摆盘装饰，展示成果 → 每组选出一名代表介绍自己的菜品特点和创作想法

观察点：操作的安全性和规范性 / 团队分工配合的效果 / 成品的色香味评判 / 创意和用心程度的体现

记录表：烹饪体验评价表

总结（10分钟）

大家共同品尝各组制作的农家菜，评选"最佳味道奖""最具创意奖"等荣誉，邀请厨师点评各组作品，回顾今天学习的烹饪知识和技能，总结收获和不足，布置课后实践任务：回家后尝试为家人做一道简单的农家菜

四、评价

方式：过程性评价

量规：从安全操作（20分）、知识掌握（20分）、实践技能（30分）、团队合作（15分）、创意表现（15分）五个维度进行评分，总分100分

反思：今天你学到了哪些新的烹饪知识？ / 在制作过程中遇到了什么困难？你是如何解决的？ / 你觉得农家菜和城市里的菜品有什么不同？ / 如果以后还要继续学习烹饪，你最想学哪道菜？

五、附录

任务单：课后任务：请利用周末时间，在家中使用本地可获得的食材，为家人制作一道最简单的农家菜（如炒土豆丝或蒜蓉青菜），记录制作过程并拍照，下次回课时带来分享
