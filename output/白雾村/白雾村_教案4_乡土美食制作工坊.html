乡土美食制作工坊

类型：体验 | 板块：劳动

年级：小学5-6年级 | 时长：90分钟

地点：白雾村农家乐厨房及菜园 | 容量：30人

一、课程目标

知识：认识白雾村常见当季蔬菜及农作物 / 了解云南山区农家菜的基本烹饪方法 / 知道食材从田间到餐桌的完整过程

能力：掌握基本的蔬菜清洗和刀工技巧 / 能够独立完成简单菜肴的烹制 / 培养团队协作和动手实践能力

情感：体会劳动的艰辛与收获的喜悅 / 增进对乡村饮食文化的认识与尊重 / 感受田园生活的纯朴与美好

二、课程准备

教师：准备农家柴火灶或电磁炉若干台 / 准备当地当季新鲜蔬菜和基本调味品 / 打印学生任务单和食材识别图卡 / 邀请当地村民讲解当地饮食文化

学生：穿轻便耐脏服装和运动鞋 / 修剪指甲，避免操作时受伤 / 自带围裙和洗碗布 / 预习当地常见蔬菜的名称和特征

安全预案

⚠ 刀具使用不当造成切伤 → 全程由导师示范并指导操作，提供儿童安全刀具，发现问题及时处理
⚠ 柴火灶或燃气使用时烫伤 → 保持安全距离，设置防烫隔热装置，安排助教现场监督
⚠ 油锅溅出造成烫伤 → 演示正确倒油和翻炒姿势，提供长柄锅铲和隔热手套

三、实施过程

导入（10分钟）

在 village meeting point welcome students, introduce the day s food-making journey, ignite interest with a question about their favorite village dish

主体活动

活动1：田园探索小分队（15分钟）

步骤：步行前往附近菜园或农田 → 由村民导师带领识别3-5种当季蔬菜 → 观察了解植株形态和生长环境 → 返回时每人采摘1-2种所需食材

观察点：蔬菜叶片形状和颜色 / 种植方式和生长环境 / 是否可以食用及食用部位

记录表：《食材识别记录卡》

活动2：美味传承课堂（25分钟）

步骤：观看农家婆婆现场示范1-2道特色农家菜烹饪 → 聆听讲解配料比例和火候控制要点 → 了解当地烹饪习俗背后的故事 → 小组讨论并记录关键步骤

观察点：烹饪手势和工具使用 / 调味料的种类和用量 / 火候变化的时机把握

记录表：《菜谱步骤记录表》

活动3：小小厨师选拔赛（15分钟）

步骤：分组进行食材预处理比赛 → 在规定时间内完成蔬菜清洗和切配 → 互相评分，选出最佳小组 → 导师点评并示范正确手法

观察点：操作规范和效率 / 刀具使用的安全性 / 团队配合默契度

记录表：《技能比赛计分表》

活动4：我是乡土小厨神（25分钟）

步骤：领取食材和工具，独立完成菜品制作 → 尝试复刻学习的菜谱或自主创新 → 装盘并为自己的菜品命名 → 作品展示和互相品尝点评

观察点：成品的外观和味道 / 创新点和亮点 / 完成过程中的困难和解决办法

记录表：《菜品评价展示卡》

总结（10分钟）

引导学生回顾整个制作过程，分享品尝自己亲手做的菜的感受，感恩农户的指导和食材的馈赠，鼓励学生在家尝试为家人做一顿饭，延展乡村美食文化的传承意义

四、评价

方式：过程性评价

量规：从探索参与度、知识掌握度、技能操作规范性、创意表现、合作精神五个维度进行综合评价，采用星级评定和文字描述相结合的方式

反思：你认为一道好吃的农家菜，需要具备哪些要素？ / 今天的制作过程中，你觉得哪个环节最有挑战性？ / 如果让你改良这道菜，你会怎么做？

五、附录

任务单：《乡土美食制作工坊任务单》：含食材识别记录、菜谱步骤笔记、自评与互评表

素材：白雾村当季蔬菜图谱 / 基础刀工示范图解 / 安全操作注意事项卡 / 菜品创意展示模板
