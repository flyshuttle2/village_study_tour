乡村美食探索课堂

类型：探究 | 板块：劳动

年级：小学3-4年级 | 时长：90分钟

地点：白雾村农户菜园及乡村厨房 | 容量：30人

一、课程目标

知识：认识白雾村常见的农作物和蔬菜品种 / 了解食材的生长环境与季节性 / 学习当地农家菜的基本烹饪知识

能力：能够辨别常见的可食用蔬菜 / 掌握基础的食物清洗和处理技能 / 提升团队协作与动手操作能力

情感：培养对食物来源的感恩之心 / 增强对乡村饮食文化的兴趣 / 树立节约粮食的意识和劳动最光荣的价值观

二、课程准备

教师：联系当地农户确定菜园参观和厨房体验场地 / 准备食材介绍卡片、记录表、安全工具 / 了解当地季节性蔬菜和特色菜品

学生：穿着舒适便于活动的服装和鞋子 / 自带水杯和笔记本 / 预习基本的蔬菜名称

安全预案

⚠ 菜园行走时地面湿滑摔倒 → 选择干燥路径，安排教师全程陪同引导
⚠ 刀具使用可能划伤手指 → 提供儿童安全塑料刀，演示正确握持方法，教师现场指导
⚠ 户外蚊虫叮咬或过敏 → 提前喷洒驱蚊液，准备应急药膏

三、实施过程

导入（10分钟）

出示图片引导学生回忆平时吃过的蔬菜，导入问题'这些蔬菜从哪里来'，介绍本次课程目标和探索路线

主体活动

活动1：菜园探索之旅（15分钟）

步骤：前往农户菜园，观察各类蔬菜种植情况 → 由农户介绍常见蔬菜的名称、生长特点 → 学生每人识别并记录3-5种蔬菜 → 简单讲解蔬菜的采摘要领

观察点：蔬菜叶子的形状和颜色 / 种植方式（平地还是梯田） / 蔬菜生长环境的水源条件

记录表：蔬菜辨识记录表

活动2：乡村美食课堂（25分钟）

步骤：农户讲解白雾村特色农家菜的食材搭配 → 介绍当季蔬菜的营养价值和食用方法 → 展示一道特色菜的全套食材 → 讲解基础烹饪步骤和安全注意事项

观察点：食材之间的搭配原则 / 当地特有的烹饪手法 / 饮食文化中的习俗寓意

记录表：美食知识笔记

活动3：食材连连看游戏（20分钟）

步骤：分组进行，每组抽取食材卡片 → 根据描述快速找出对应的蔬菜实物 → 小组竞争，正确率最高者获胜 → 教师点评并补充食材知识

观察点：对食材特征的掌握程度 / 反应速度和团队配合

记录表：游戏积分表

活动4：小小厨师体验（25分钟）

步骤：分组领取食材和简易制作工具 → 在农户指导下清洗、切配食材 → 动手制作凉拌黄瓜或简单面食 → 完成后互相品尝评价

观察点：工具使用的安全性 / 食材处理的卫生程度 / 成品的口感和外观

记录表：制作过程记录表

总结（10分钟）

引导学生分享今日收获，回顾食材从田间到餐桌的过程，强调食物的来之不易，感恩农户的辛勤劳动，呼吁珍惜食物、热爱劳动

四、评价

方式：过程性评价

量规：观察学生在探索、学习、游戏、制作各环节的参与度和表现，重点评价对食材的认识、动手操作的积极性和团队合作精神，结合成品完成质量进行综合评定

反思：今天你认识了哪些蔬菜？它们是怎么生长的？ / 在做菜的过程中你觉得哪个步骤最难？你是如何解决的？ / 通过这次课程，你对乡村美食有什么新的理解？

五、附录

任务单：乡村美食探索任务单，包含：我认识的蔬菜（图文记录）、我的小发现（观察心得）、我制作的美食（成品照片记录）、我的收获（总结感想）

素材：蔬菜辨识图片卡 / 食材连连看游戏卡牌 / 学生制作工具（儿童塑料刀、砧板、碗碟） / 制作食材（黄瓜、青菜、面粉等）
