古村黄酒酿造体验

类型：体验 | 板块：劳动

年级：小学5-6年级 | 时长：90分钟

地点：龙潭村传统酿酒作坊 | 容量：30人

一、课程目标

知识：屏南黄酒酿造技艺的非遗历史文化 / 糯米酒酿造的基本工序流程 / 酿造用糯米、酒曲、水的比例配比知识

能力：掌握糯米浸泡、蒸煮的基本操作技能 / 学会使用酒曲进行发酵的方法 / 能够描述黄酒酿造的全流程

情感：体会传统酿造技艺的文化价值与劳动意义 / 培养耐心细致的劳动态度 / 增强对非遗文化的认知与保护意识

二、课程准备

教师：提前预约传统酿酒作坊作为教学场地 / 准备糯米、活酒曲、酿酒工具（蒸桶、缸、坛等） / 准备黄酒酿造的历史文化讲解资料 / 准备儿童酿酒操作的安全工具

学生：穿着舒适耐脏的衣服和便于操作的鞋子 / 预习黄酒酿造的基本知识 / 携带笔和任务单

安全预案

⚠ 蒸米饭时蒸汽烫伤 → 使用专用隔热手套，由导师演示规范操作，儿童不直接接触蒸汽
⚠ 酒曲过敏 → 如有酒精过敏史的学生需提前告知，由导师评估是否适合参与直接操作

三、实施过程

导入（10分钟）

导入屏南黄酒文化：讲述屏南黄酒在当地的地位和传说故事，激发学生对酿造技艺的兴趣

主体活动

活动1：探索酿酒作坊（15分钟）

步骤：分组进入传统酿酒作坊 → 导师引导观察酿造工具和环境 → 学生记录发现的酿造工具和原材料 → 小组讨论并提出问题

观察点：酿酒作坊的建筑特点 / 使用的传统工具如蒸桶、酒缸、酒坛 / 酒曲的外观和气味 / 发酵环境的温度和湿度控制

记录表：探索发现记录表

活动2：学习酿造知识（25分钟）

步骤：导师讲授屏南黄酒酿造技艺的历史渊源 → 介绍酿造的主要工序流程 → 讲解糯米选择、处理、蒸煮的关键要点 → 示范酒曲的使用方法和配比 → 互动问答加深理解

观察点：学生是否理解各工序的先后顺序 / 是否能说出糯米、酒曲、水的比例 / 对酒曲作用的理解程度

记录表：知识学习笔记本

活动3：酿酒动作游戏（15分钟）

步骤：角色分配：每组扮演酿酒小工匠 → 使用模拟材料（替代糯米）练习洒水动作 → 练习拌曲手势和力度控制 → 装坛模拟动作竞赛 → 小组展示并相互评分

观察点：动作的规范性和协调性 / 参与游戏的积极性和团队协作

记录表：游戏竞赛评分表

活动4：亲手酿造黄酒（35分钟）

步骤：领取个人酿酒工具和材料 → 按工序步骤进行：浸泡糯米30分钟 → 蒸饭：观察糯米变成熟饭 → 摊凉：将米饭均匀铺开降温 → 拌曲：按比例放入酒曲并搅拌均匀 → 装坛：将拌好的米饭装入酒坛 → 封装：在标签上写下姓名和日期 → 将酒坛交由酿酒坊统一管理发酵

观察点：各工序操作的规范性 / 糯米蒸煮的成熟度判断 / 酒曲拌匀的程度 / 操作安全意识的体现

记录表：酿造操作记录表

总结（10分钟）

回顾黄酒酿造的核心工序流程，分享酿造过程中的感受和收获，介绍发酵完成后可回访取酒或邮寄到校的计划，强调这是屏南重要的非遗文化，需要保护和传承

四、评价

方式：过程性评价

量规：探索环节能发现3样以上酿酒工具得满分；学习环节能完整复述5道以上工序得满分；游戏环节动作规范且积极参与得满分；酿造环节完成全部工序且操作基本规范得满分

反思：酿酒过程中哪个环节你觉得最有意思？ / 为什么要用酒曲来酿造黄酒？ / 你认为传统酿造技艺为什么值得保护？
