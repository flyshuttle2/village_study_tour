传统手工艺文创设计

类型：创造 | 板块：艺术

年级：小学5-6年级 | 时长：90分钟

地点：龙潭村非遗工坊 | 容量：30人

一、课程目标

知识：了解龙潭村传统手工艺的历史与文化内涵 / 掌握竹编/草编的基本编织技法 / 认识传统手工艺与现代文创设计的关联

能力：能够运用经纬编织法进行基本编制 / 能够独立完成简单纹样的设计与制作 / 提升创造性思维与动手实践能力

情感：增强对传统手工艺的保护与传承意识 / 培养文化自信与乡土认同感 / 激发创新创作的热情

二、课程准备

教师：提前联系本地手工艺传承人作为授课教师 / 准备竹编/草编原材料（竹篾、草绳） / 准备剪刀、尺子、钉板等编制工具 / 打印学员任务单 / 准备往期优秀作品案例图片

学生：穿着舒适的衣物，便于动手操作 / 携带彩笔或马克笔用于装饰创作 / 预习龙潭村传统手工艺相关知识

安全预案

⚠ 竹篾/草绳锋利割伤手指 → 分发材料时提醒注意安全，使用剪刀时规范操作
⚠ 工具使用不当造成伤害 → 传承人示范正确使用方法，助教巡视指导

三、实施过程

导入（10分钟）

在展示馆前集合，简要回顾龙潭村传统手工艺文化，介绍本次课程目标与流程，发放任务单

主体活动

活动1：传统手工艺探索（15分钟）

步骤：组织学员有序进入展示馆 → 传承人引导参观并讲解各类传统手工艺品 → 学员观察并记录感兴趣的手工艺种类、技法特点 → 提出问题：这些手工艺是如何制作的？有什么用途？

观察点：传统手工艺品的外观特征、编织纹理 / 不同器具的造型与功能特点 / 手工艺品的文化寓意与实用价值

记录表：探索发现记录表

活动2：编织技法学习（40分钟）

步骤：传承人示范基础编织技法：起头、经纬交织、收边 → 讲解每种技法的要点与注意事项 → 学员跟随传承人练习基本动作 → 学习简单纹样如平纹、斜纹的制作方法 → 了解如何将传统技法应用于现代文创设计

观察点：编织手势与力度控制 / 经纬线的排列与交织方式 / 收边的美观性与牢固度

记录表：技法练习记录表

活动3：文创作品设计与制作（35分钟）

步骤：思考设计灵感：可融入龙潭村文化元素（如梯田、廊桥、芙蓉李等） → 在任务单上绘制设计草图 → 选择合适的编织技法进行制作 → 完成后进行装饰美化 → 作品展示与简短介绍

观察点：设计构思的创新性与文化性 / 制作的完整性与精细度 / 作品的文化表达与创意呈现

记录表：创意设计制作单

总结（10分钟）

学员展示并介绍自己的文创作品，传承人点评与建议，回顾本节课学习的编织技法，拓展思考：如何在生活中运用传统手工艺进行创新设计，鼓励学员成为小传承人

四、评价

方式：过程性评价

量规：探索环节：观察仔细、提问积极；学习环节：技法掌握、基本功扎实；创造环节：创意新颖、制作完整、作品美观

反思：你最喜欢哪种传统手工艺？为什么？ / 在制作过程中遇到了什么困难？你是如何解决的？ / 你希望将来如何运用今天学到的技艺？

五、附录

任务单：龙潭村传统手工艺文创设计任务单：含探索发现区、技法练习区、创意设计草图区、作品展示区；材料清单：竹篾60cm×8根/组、草绳30cm×5根/组、剪刀1把、钉板1块、彩笔1套；往期优秀作品案例图册若干

素材：竹编成品示例 / 草编成品示例 / 编织工具套装 / 文创设计案例图册
