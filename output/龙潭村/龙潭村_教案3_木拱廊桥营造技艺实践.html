木拱廊桥营造技艺实践

类型：体验 | 板块：人文

年级：小学3-4年级 | 时长：90分钟

地点：龙潭村古廊桥遗址及村中空地 | 容量：30人

一、课程目标

知识：了解木拱桥的历史背景与文化价值 / 认识木拱桥的基本结构（主拱、副拱、桥面、廊屋） / 知晓木拱桥营造的关键技艺：榫卯结构、杠杆原理、力学平衡

能力：能够细致观察并描述木拱桥的结构特征 / 能够运用简单的木工工具进行基础加工 / 能够在团队中分工合作完成木拱桥模型的搭建

情感：增进对闽东传统建筑文化的认识与兴趣 / 培养尊重和保护非物质文化遗产的意识 / 体会传统工匠的智慧与匠心，增强文化自信

二、课程准备

教师：PPT课件或图片（包含木拱桥结构解析图、施工步骤图） / 小木拱桥模型成品展示件 / 木工工具（儿童安全锯、砂纸、钉子或粘合剂） / 木质材料（按小组数量准备，每组约50根小木条、若干木板） / 安全手套、围裙 / 记录表（学生任务单）

学生：穿着舒适便于活动的服装 / 铅笔、橡皮用于记录 / 提前了解屏南木拱廊桥相关资料（可布置预习任务）

安全预案

⚠ 使用工具时的割伤、刺伤 → 全程佩戴安全手套，正确示范工具使用方法，安排助教协助看护
⚠ 搬运材料时的碰撞 → 指定材料放置区域，告知学生有序取放，不要奔跑

三、实施过程

导入（10分钟）

导入：展示龙潭村古廊桥照片或视频片段，提问「同学们见过这样的桥吗？知道它是用什么建造的吗？」引发学生对木拱桥的关注与兴趣

主体活动

活动1：探索古廊桥（15分钟）

步骤：1. 带领学生到达古廊桥遗址或展示廊桥实物图片 → 2. 分组发放观察记录表，引导学生从整体外形、结构细节、材质、装饰等方面进行观察 → 3. 提出思考问题：这桥是怎么搭建的？不用一颗钉子能搭起来吗？ → 4. 学生记录观察发现，小组交流分享

观察点：廊桥的整体形态（拱形桥身、廊屋结构） / 桥身主要材质（木头种类、表面处理） / 连接方式（是否能看到榫卯、穿插痕迹） / 桥上装饰（雕刻、彩绘等）

记录表：古廊桥观察记录表

活动2：学习木拱桥营造知识（30分钟）

步骤：1. 讲授木拱桥的历史与文化意义（屏南是中国木拱廊桥之乡，已有千年历史） → 2. 解析木拱桥的结构原理：介绍主拱系统、副拱系统、桥面板、廊屋四大部分 → 3. 讲解核心营造技艺：榫卯结构的巧妙应用、杠杆原理与力学平衡、无钉建桥的智慧 → 4. 通过图片或短视频展示传统木拱桥的建造过程（选料、烤木、架拱、上梁等工序） → 5. 知识问答互动，检验学生学习效果

观察点：学生对结构各部分名称的掌握 / 对榫卯原理的理解程度 / 对传统营造工序的认知

记录表：知识学习笔记本

活动3：搭建木拱桥模型（45分钟）

步骤：1. 分组（每组4-5人），分配材料和工具，说明搭建目标和要求 → 2. 每组讨论设计方案，先画简单的结构草图 → 3. 按照「底座加固→搭建主拱→铺设桥面→装饰美化」的顺序进行搭建 → 4. 过程中导师巡回指导，及时纠错和示范关键步骤 → 5. 各组完成后展示作品，介绍设计思路和搭建难点 → 6. 评选「最具创意奖」「最牢固奖」等进行鼓励

观察点：小组分工合作情况 / 工具使用的安全性 / 搭建过程中遇到的问题及解决方式 / 作品的完整性和稳固性

记录表：木拱桥模型搭建记录表

总结（10分钟）

总结延伸：1. 请学生分享本次课程的最大收获和感受 2. 提问「除了木拱桥，你还知道哪些屏南的传统技艺？」引出其他非遗项目 3. 布置课后任务：回家后向家人介绍今天学习的木拱桥知识，或尝试用家中材料搭建更小的桥模型 4. 鼓励学生成为小小文化传承人，关注和保护家乡的传统建筑文化

四、评价

方式：过程性评价

量规：观察记录表（15分）+ 知识问答表现（15分）+ 模型搭建成果（40分）+ 团队合作与参与度（20分）+ 课堂总结发言（10分）= 总分100分

反思：你觉得搭建木拱桥最难的部分是什么？你是怎样解决的？ / 今天的课程让你对传统建筑技艺有了什么新的认识？ / 如果你是一名小工匠，还会想怎样改进你的桥模型？

五、附录

任务单：《木拱桥营造小工匠》任务单：1. 观察记录（古廊桥外观描写） 2. 知识填空（结构名称、营造技艺要点） 3. 设计草图画出你想搭建的桥 4. 搭建过程记录（步骤、问题、解决方法） 5. 心得分享（所学、所得、所感）

素材：木拱桥结构示意图 / 传统营造工序图解 / 儿童安全锯、砂纸 / 小木条（长30cm左右）、小木板 / 绳子或牙签作固定 / 彩色贴纸用于装饰
